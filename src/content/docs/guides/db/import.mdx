`@rljson/db` is the database management system of Rljson. It stores Rljson
tables on an `Io` backend, in memory, on disk or on a server, and gives you
one interface to read and write them: routes to address data, joins to build
views, edits to change many rows at once, and histories to go back.

This chapter works with the car world from [World of
Cars](/guides/generate/usecase/): one manufacturer, Velora, with a catalog
of five cars, their prices, brands, workshops and bills of materials.

<UsecaseOverview />

You will learn how to:

- create a Db on an in memory Io
- create the tables and import the data
- read a column of the catalog with a route

## 1. Set up the project

Create a project and install Db, an Io backend, the generator and the core
packages:

```bash
mkdir car-db
cd car-db
echo '{ "type": "module" }' > package.json
pnpm add @rljson/db @rljson/io @rljson/edge @rljson/rljson @rljson/hash
```

All pages of this chapter share one file, `car-world-db.ts`. It generates
the world and imports it into a Db. Each page then adds an application of
its own, like `import.ts` on this page.

## 2. Create the Db and import the world

A `Db` works on an `Io`. `IoMem` keeps everything in memory, which is all a
tutorial needs. Db reads the type of each table, cake, layer, slice ids or
components, from its table configuration, so the world goes in as Edge
generates it. `createTablesFromData` creates every table the world
describes, each with its insert history, which [Edit single
items](/guides/db/single-edit/) uses. Then import the world in one call:

## What you have learned

- Db is the database management system of Rljson, on top of an `Io`.
- Db reads the type of a table from its table configuration.
- `createTableWithInsertHistory` creates a table, `import` fills it.
- A route like `catalogs@ref/carBrands/brands/model` reads a
  column of a catalog.
