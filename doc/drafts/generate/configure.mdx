A preset is a configuration someone else has written. In this tutorial you
write your own: how many manufacturers, catalogs and cars, which layers,
which price range and currencies, and how popular each model is. You
estimate the size of the world before you generate it and compare the
estimate with what the run produced.

You will learn how to:

- describe a world with a `GeneratorConfig`
- give a count as a number or as a range
- estimate the rows before anything is generated
- switch layers off
- tune the values of a layer
- read the resolved configuration with all defaults

## 1. Set up the project

Create a project and install the generator and the core package:

```bash
mkdir car-world
cd car-world
echo '{ "type": "module" }' > package.json
pnpm add @rljson/generator @rljson/rljson
```

`"type": "module"` lets the application use ES modules and top-level `await`.
Now create the file `configure.ts`. Each of the following steps adds code to
it: put the imports of a step at the top of the file, and its code below the
code of the previous step. The complete file is shown at the end.

## 2. Describe the world

A configuration has a seed and sections for the manufacturers, the catalogs
and the layers. Every field but the seed is optional and has a default:

<Snippet
  file="configure.spec.ts"
  region="config"
  title="configure.ts"
/>

| Section         | Decides                                                       |
| --------------- | ------------------------------------------------------------- |
| `seed`          | The random numbers, and so the data                           |
| `manufacturers` | How many manufacturers, how many catalogs each                 |
| `catalogs`      | How many cars per catalog, the model year, the revisions       |
| `layers`        | Which aspects the cars get, and the values of each aspect      |
| `scale`         | Optional: a target number of rows, see [Generate large datasets](/guides/generate/large-datasets/) |

A count is a number or a range. `carsPerCatalog: { min: 8, max: 12 }` lets
the generator draw a size for each catalog, from the seed, so the catalogs
differ in size but every run yields the same sizes.

The numbers agree. The estimate knows the counts of the configuration and
the sharing rules of each layer, so it is exact for everything that does not
depend on chance.

<Aside type="note">
  Rows that become equal by chance, like two cars that draw the same price,
  are stored once. Then the statistics count fewer rows than the estimate.
  The estimate is an upper bound.
</Aside>

## What you have learned

- A `GeneratorConfig` describes the manufacturers, the catalogs and the
  layers of a world. Every field but the seed has a default.
- A count is a number or a range, drawn from the seed.
- `estimate` tells the size of a world before you generate it.
- A layer set to `false` is left out, and its tables stay empty.
- Every layer has settings for its values, like ranges, currencies and
  popularity.
- `config` returns the resolved configuration, which reproduces the data.
