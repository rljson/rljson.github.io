## 1. Set up the project

Create a project and install the core package and the hashing package:

```bash
mkdir car-catalog
cd car-catalog
echo '{ "type": "module" }' > package.json
pnpm add @rljson/rljson @rljson/hash
```

Now create the file `colors.ts`. Each of the following steps adds code to it.

## 8. Learnings

- Create a catalog by creating a `SliceIds` object
- Assign properties to catalog objects using layers
- A layer refers to tables by name and to rows by their hashes
- Host layers in a `LayersTable` and put all tables into an Rljson object
