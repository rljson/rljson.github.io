A generated world is a graph of references. Start at the manufacturers and
follow the references down to a car and its price, brand and workshop.

<UsecaseOverview />

You will learn how to:

- follow an array of references
- resolve the cars of a catalog from its slice ids
- look up the component a layer assigns to a car
- follow a chain of references, from a workshop to its owner
- see which rows the cars share

## 1. Set up the project

Create a project and install the generator and the core package:

```bash
mkdir car-world
cd car-world
echo '{ "type": "module" }' > package.json
pnpm add @rljson/edge @rljson/rljson
```

`"type": "module"` lets the application use ES modules and top-level `await`.
Now create the file `walk.ts`. Each of the following steps adds code to it:
put the imports of a step at the top of the file, and its code below the code
of the previous step. The complete file is shown at the end.

## 4. From a manufacturer to its catalogs

<UsecaseManufacturer />

A manufacturer lists its catalogs in `catalogsRef`, an array with one hash
per catalog, like `wheelsRef` in
[Components](/guides/data_types/components/). A catalog is a
[cake](/guides/data_types/cake/): its `sliceIdsRow` names the row of
`carIds` that lists its cars, and `layers` names one layer per aspect:

<Snippet
  file="car-world.spec.ts"
  region="catalogs"
  title="walk.ts"
/>

The id of a catalog is the manufacturer, the segment and the model year,
like `velora-cars-2026`. A slice id is the catalog followed by a number,
like `velora-cars-000001`.

<Aside type="note">
  `hip` hashes nested objects too, so `layers` carries a `_hash` of its own,
  next to the layer names. Skip the keys that start with an underscore when you
  iterate it. The same holds for the `add` of a layer.
</Aside>

## What you have learned

- The manufacturers table is the entry point. A row lists other rows with
  an array of references.
- A catalog is a cake. `resolveSliceIds` yields its cars, `layers` names
  one layer per aspect.
- A layer's `add` maps every car to a component, and `rowOf` follows the
  hash to the row.
- Components refer to components, like a workshop to its address and owner.
- Rows with equal content are stored once, however many cars use them.
