## 1. Set up the project

Create a project and install the core package and the hashing package:

```bash
mkdir car-catalog
cd car-catalog
echo '{ "type": "module" }' > package.json
pnpm add @rljson/rljson @rljson/hash
```

A row of slice ids has three fields:

| Field    | Meaning                                                  |
| -------- | -------------------------------------------------------- |
| `base`   | Optional: the hash of a row of slice ids that it extends |
| `add`    | The slice ids that are added to the base                 |
| `remove` | Optional: the slice ids that are removed from the base   |

`ref` from `@rljson/rljson` returns the hash of a row. The row of 2026 stores
only what changed. However many cars 2025 lists, the derived row stays small.

## What you have learned

- A **slice** is one object of a catalog, e.g. a car.
- A **slice id** identifies a slice, e.g. `taycan`.
- A `SliceIds` object organizes sets of slices.
- **Derived catalogs** store only its changes.
- A `SliceIdsTable` allows to manage multiple catalogs
