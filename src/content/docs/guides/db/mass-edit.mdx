Give every car above 50,000 EUR a discount of ten percent: that is one edit,
but it changes many rows. Db records such edits without touching the data.
You see their result in a view, and you write them into the data when you
publish.

<CarCake />

In the figure, every column of the catalog is a layer. A mass edit changes
one column for the rows of a view: here the discount in the prices layer.

You will learn how to:

- create the tables that store edits
- select, filter and set values with a `MultiEditManager`
- see the edited view before anything is written
- publish the edits into a new catalog

## What you have learned

- Edits are stored in three tables per cake.
- A `MultiEditManager` chains edits: select, filter, set value.
- `manager.join` shows the edited view before anything is written.
- `publish` writes the edits into a new catalog.
