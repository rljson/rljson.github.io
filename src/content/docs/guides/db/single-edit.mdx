The Velora Amita costs 18,600 EUR. Lower its price to 17,990 EUR. Rljson
data never changes in place: a new price needs a new prices layer, and the
new layer a new catalog. The old catalog stays as it is.

<UsecaseCar />

This page changes the price box in the figure, and only that.

You will learn how to:

- read a value with a route
- isolate a row from a tree and inject a new one
- insert a changed value on a route
- read the insert history

## 2. Insert a new price

Get the prices of the catalog with the same route. `isolate` copies the
tree along the path of the Amita, `inject` puts the changed price at its
end. `db.insert` on the route of the catalog does the rest: it writes a
new price, a new prices layer that builds on the old one, and a new catalog
that keeps all other layers. It returns a row of the insert history with
the hash of the new catalog:

## What you have learned

- `db.get` returns cells with the row and its path in a tree.
- `isolate` and `inject` build the tree an insert needs.
- An insert on a route creates a new component, a new layer and a new cake.
- Every insert is recorded in the insert history of its table.
