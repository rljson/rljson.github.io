A `Cake` is a set of independent layers assigning different properties to the same
objects. In this tutorial let's create a cake, that describes the colors, the
brands and the prices of the cars in a catalog.

## 1. Set up the project

Create a project and install the core package and the hashing package:

```bash
mkdir car-catalog
cd car-catalog
echo '{ "type": "module" }' > package.json
pnpm add @rljson/rljson @rljson/hash
```

Now create the file `cake.ts`. Each of the following steps adds code to it.

## What you have learned

- A cake composes layers that assign properties to the same slices
- All layers of a cake share one `SliceIds` object
- A cake takes at most one layer from each layers table
- A cake refers to its layers by their hashes
